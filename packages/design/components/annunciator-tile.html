Annunciator tile

A latching alarm indicator: it flashes until an operator acknowledges it, stays lit steady while the condition remains active, and — once the condition clears — stays lit in a distinct colour until the operator presses reset. Every state has its own icon glyph and its own text label, so the state reads the same with the colour removed.
