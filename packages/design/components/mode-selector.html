Mode selector

A chunky physical mode switch. Built on native <input type="radio"> elements, so Tab moves to the group, arrow keys move between positions, and a screen reader announces "radio button, 2 of 4" the same way it would for any radio group — no custom keyboard handling to get wrong.

Mixer drive mode

The selected position uses --cb-color-accent-amber with --cb-color-on-accent-amber ink (5.59:1 light, 8.72:1 dark, 6.43:1 Kid mode).
