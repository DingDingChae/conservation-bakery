Command palette

Ctrl+Shift+F anywhere on this page, or the button below, opens the palette. It filters a fixed command list by an anchored regular expression built from what you type plus the four toggles. Built on the native <dialog> element, so focus trapping and Escape-to-close come from the browser, not from hand-written focus management.

Command palette

    Arrow keys move the active option, Enter runs it, Escape closes. Invalid patterns (an unbalanced group, for example) are caught and shown as text in the status line — the palette never throws.
