Setpoint vs process value readout

Setpoint (SP) and process value (PV) as tabular-figure numerals, plus a status word — "within tolerance", "deviation high", "deviation low" — that is always present as text, never implied by colour alone. The small bar and marker underneath are decorative and aria-hidden; a screen reader gets the same information from the definition list and the status text.
