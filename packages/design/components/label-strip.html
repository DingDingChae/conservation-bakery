Engraved label strip

Identifies a control or a group of controls, the way a real machined nameplate does. A label strip is never decorative-only text: its id is the target of an aria-labelledby on the control it names, so the visual label and the accessible name are the same string, spoken the same way a operator reads it off the panel.

Mixer drive
Oven zone 1
Deviation trip

Labelling a real control:

Cooler belt speed

Uses --cb-color-label-bg, --cb-color-label-text and --cb-letter-spacing-label. The label/background pair is 13.28:1 in the light scheme and 16.02:1 in the dark scheme — see src/contrast.spec.ts.
